## Purpose

The purpose of this repository is to train myself on making secure production grade applications supply chains.\
I will mainly focus my understanding around front-end development but I will also surely explore more in dept about CI/CD, docker and other security scanning practices.

We recently saw a lot of npm supply chain outrage (axios for example) and as the ecosystem grow, it will probably get worst and worst.\

Today, we rely more and more on tiers libraries that rely on tiers libraries that rely on... well, you understand.\
This multiply the attack surfaces for potential hackers.

Supply chain security is starting to become more and more important as this is a kind of attack that is hard to anticipate, detect and mitigate.

In a first place, I will mainly focus on **SBOM generation and analysis**.
